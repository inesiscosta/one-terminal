<ShowcaseList />

## Add your site

Using One Terminal? Add your site to the list:

1. Edit [`website/src/data/showcase.ts`](https://github.com/inesiscosta/one-terminal/blob/main/website/src/data/showcase.ts)
   and add an entry with your site's name, a one-line description and its URL.
2. Open a pull request.

Only list your own site, or one you have permission to list.
