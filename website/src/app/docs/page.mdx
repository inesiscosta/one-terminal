# Getting Started

**One Terminal** is a React component that renders a fake but convincing terminal. Visitors can `cd` around a
virtual file system you define, `cat` your files, `grep` them, pipe commands together, and run your own custom
commands. It is ideal for portfolios, landing pages, docs, and easter eggs.

- **Zero dependencies.** Just React 18 or newer.
- **Feels real.** Quotes, pipes, flags, tab completion, history search (`Ctrl+R`), `!!`, and readline shortcuts.
- **Fully themeable.** Built-in themes, macOS / Windows / Linux window frames, and custom cursors.
- **Extensible.** Add your own commands, override built-ins, or script an automated demo.

## Installation

```bash npm2yarn
npm install one-terminal
```

## Quick Start

<Steps>

### Describe your files

The terminal doesn't touch the real disk. You give it a tree of folders and files as a plain object.

```tsx
import type { DirectoryNode } from 'one-terminal';

const files: DirectoryNode = {
  kind: 'directory',
  entries: {
    'about.txt': {
      kind: 'file',
      fileType: 'text',
      content: "Hi! I'm a developer who loves terminals.",
    },
    projects: {
      kind: 'directory',
      entries: {
        'one-terminal.md': { kind: 'file', fileType: 'text', content: '# One Terminal\nA React terminal.' },
      },
    },
    'github.lnk': { kind: 'file', fileType: 'link', href: 'https://github.com', label: 'My GitHub' },
  },
};
```

### Render the terminal

Give it a parent with a height. The terminal fills its container.

```tsx
import { Terminal } from 'one-terminal';

export default function App() {
  return (
    <div style={{ height: 400 }}>
      <Terminal fileStructure={files} welcomeMessage="Type 'help' to get started." />
    </div>
  );
}
```

### Try it

Click the terminal and type `ls`, `cat about.txt`, `cd projects`, `tree`, or `help`. This one is live:

</Steps>

## A more complete example

```tsx
<Terminal
  fileStructure={files}
  startPath="/projects"
  username="ines"
  hostname="portfolio"
  prompt="{user}@{host}:{path}$ "
  theme="monokai"
  windowChrome={['mac', { titleBarText: 'ines — portfolio' }]}
  welcomeMessage="Welcome! Try 'neofetch' or 'help'."
  neofetch={{ info: { Role: 'Software Engineer', Location: 'Lisbon' } }}
  extraCommands={{
    hello: { description: 'Say hi', run: (args) => `Hello, ${args[0] ?? 'stranger'}!` },
  }}
/>
```
